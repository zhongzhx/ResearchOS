# Weekly Report Schema

## Sections

1. One-paragraph summary.
2. Literature progress.
3. Knowledge-base additions.
4. Experiment/design/result progress.
5. Bottlenecks and risks.
6. Decisions made.
7. Questions for advisor.
8. Next-week plan.

## Style

- Be short enough for an advisor to scan.
- Distinguish completed work from planned work.
- Use project evidence when available.
- Mark empty sections as "No new record found" rather than inventing progress.
