# Bottleneck Diagnostic Model

## Common Bottleneck Classes

- Scope bottleneck: research question is too broad or variables are not defined.
- Evidence bottleneck: missing key literature, weak novelty, or contradictory evidence.
- Design bottleneck: missing control group, baseline, replicate, or evaluation metric.
- Execution bottleneck: protocol instability, sample quality, contamination, batch effect, equipment limitation.
- Data bottleneck: missing data, noisy data, low sample size, inaccessible dataset, inconsistent format.
- Interpretation bottleneck: result does not connect to the hypothesis or mechanism.
- Resource bottleneck: time, budget, reagent, instrument, computation, or permission constraint.
- Compliance bottleneck: human subjects, animal work, clinical data, hazardous materials, or restricted datasets.

## Diagnostic Output

For each likely cause, output:

- Evidence signal.
- Why it matters.
- Quick validation check.
- Low-risk fix.
- Higher-risk route.
- Decision checkpoint.

## Decision Rule

Prefer the smallest validation that can falsify a cause before redesigning the whole project.
