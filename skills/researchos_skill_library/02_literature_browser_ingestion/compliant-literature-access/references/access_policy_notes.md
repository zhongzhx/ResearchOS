# Access Policy Notes

Use this reference when deciding whether a download route should be enabled for a project.

## Allowed Patterns

- Open-access full text from PMC, Europe PMC, Unpaywall, publisher OA pages, or other lawful OA sources.
- Publisher-provided TDM/API links when the user or institution has the required entitlement and API key.
- Campus IP/VPN access when the agent runs on the authorized user's machine or institution-controlled server.
- EZproxy access when the user has saved their own local credentials and the institution permits this access pattern.

## Disallowed Patterns

- Saving credentials in repository files, prompt text, logs, or shared configs.
- Circumventing paywalls, CAPTCHA, MFA, SSO restrictions, robots restrictions, or anti-bot controls.
- Reusing one user's subscription access for other users or customers.
- Redistributing subscription PDFs or using them for cross-customer model training.

## Bulk Download Guidance

For thousands of records or recurring monitoring jobs, use official TDM/API access and document the license or institutional approval. Browser-style or proxy-style access is best limited to user-controlled, smaller, auditable retrieval jobs.
